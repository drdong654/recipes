# Caesar — An Interactive Cooking Experience

Интерактивное приготовление салата «Цезарь» с курицей: ингредиенты с пересчётом порций, пять этапов, чек-листы, независимые таймеры и сохранение прогресса.

## Стек

React 19, TypeScript, Vite, Tailwind CSS 4, Motion for React, Lucide React, Vitest и React Testing Library. Приложение статическое и хранит прогресс в localStorage.

## Запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run test
npm run lint
npm run build
```

## Публикация

Используйте репозиторий `recipes`, включите **Settings → Pages → Build and deployment → GitHub Actions**, затем отправьте код в ветку `main`. Workflow `.github/workflows/deploy.yml` соберёт и опубликует `dist`. В `vite.config.ts` задан `base: '/recipes/'`; при другом имени репозитория измените этот путь.

## Фотографии

Шесть сгенерированных фотографий в формате WebP находятся в `src/assets`: готовый салат, продукты, курица, крутоны, соус и финальная подача. Изображения подключены локально, без внешнего фотохостинга. При замене достаточно подставить новые файлы с теми же именами и проверить кадрирование на телефоне и компьютере. Внешний референс из спецификации в рабочей папке отсутствует.

## Таймеры

Таймеры используют абсолютное время завершения, поэтому правильно пересчитываются после обновления страницы и возвращения из фоновой вкладки. Браузер может приостанавливать JavaScript в фоне; звуковой сигнал зависит от разрешённого пользователем взаимодействия и не заменяет системные уведомления.
